###  Proyectos destacados

####  SINTRAP — Sistema Integrado de Transporte Público
Aplicación de transporte corporativo con frontend, backend y Supabase como capa de datos, con roles de administrador, conductor y colaborador.
- Mapas interactivos y ruteo
- Manejo de geometrías PostGIS vía funciones RPC de Supabase
- Gestión de horarios, notificaciones y seguimiento en tiempo real

 **Repo:** [sintrap-uv/sintrap](https://github.com/sintrap-uv/sintrap)

#### 🐾 MisMascotasApp
Aplicación móvil (React Native/Expo) con backend en Django + django-ninja (rutas estilo FastAPI sobre el ORM de Django) e integración con Firebase.
- Backend Django con django-ninja para exponer API tipo FastAPI
- Autenticación/almacenamiento vía Firebase
- Entorno dockerizado con PostgreSQL

 **Repo:** [johann199/MisMascotasApp](https://github.com/johann199/MisMascotasApp)

- Frontend con Astro + TypeScript
- Backend propio con Docker Compose
- Diseño de base de datos documentado (diagrama ER)

 **Repo:** [johann199/CRM-ERP-Plataform](https://github.com/johann199/CRM-ERP-Plataform)
